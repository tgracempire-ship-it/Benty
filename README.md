# DAVID Engineering & Consulting — Landing Page

A standalone, pixel-accurate static website for **David Engineering & Consulting**.

## Folder Structure

```
BEnty/
├── index.html          ← Main entry point
├── css/
│   ├── style.css       ← All layout, theme & component styles
│   └── icons.css       ← Icon/illustration helper styles
├── js/
│   └── main.js         ← Animations, counter effects, interactions
├── images/
│   ├── favicon.svg     ← Browser tab icon
│   └── hero-bg.jpg     ← Hero background (add your own photo here)
└── README.md           ← This file
```

## How to Run

1. Simply open `index.html` in any modern browser.
2. No build step, no dependencies to install.

## Hero Image

The hero section looks for `images/hero-bg.jpg`.  
Download a free construction site photo from [Unsplash](https://unsplash.com/s/photos/construction-site) and save it as `images/hero-bg.jpg` for best results.

## Color Palette

| Token        | Hex       | Usage                    |
|-------------|-----------|--------------------------|
| `--teal`    | `#0F3E4D` | Primary / navbar / text  |
| `--gold`    | `#EFA526` | CTAs / highlights        |
| `--off-white`| `#F8FAFC`| Page background          |
| `--slate`   | `#E2E8F0` | Borders / dividers       |

## Customization

- Replace placeholder text in `index.html` with real contact info.
- Swap the inline SVG logo with your actual logo image.
- Add your hero background photo to `/images/hero-bg.jpg`.
